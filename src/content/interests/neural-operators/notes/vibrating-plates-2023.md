# Learning to Predict Structural Vibrations

**Authors:** Jan van Delden; Julius Schultz; Christopher Blech; Sabine C. Langer; Timo Lüddecke

**Publication:** NeurIPS 2024; first arXiv posting 2023

Introduces a 12000-geometry harmonically excited plate benchmark and Frequency-Query Operator, comparing FNO and DeepONet baselines.

Forward vibration prediction is already studied. A sparse-sensor inverse task would be a proposed adaptation. Code and data links: https://github.com/ecker-lab/Learning_Vibrating_Plates ; published example dataset is 4 GB, full subsets 21 GB.

[Primary source](https://arxiv.org/abs/2310.05469)

**Review:** Primary abstract/bibliographic screening, 14 September 2026. No numerical results independently reproduced.
