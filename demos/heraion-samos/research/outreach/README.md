## What these drafts ask for that the brief's version did not

- **Scope, stated up front.** Each names the Polykrates temple as the target and
  says plainly what the project is, so nobody has to guess whether you are a
  student, a vendor, or a documentary crew.
- **The Early Bronze Age / Great Temple distinction.** The Kouka draft does not
  pretend her team's model is of the temple. Asking her for "the Heraion 3D model"
  as though it were the temple would signal you had not read the project page.
- **A named fallback ask.** Every draft has a second, much cheaper question that
  can be answered in one line even if the files are unavailable. A request that
  can only be answered yes-or-no-with-effort often gets no answer at all.
- **Commercial status disclosed, not buried.** If the app is ever ticketed or
  sponsored, saying so now costs one sentence. Discovering it after they grant
  research-only terms costs the whole permission round.
