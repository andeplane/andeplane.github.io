Why a scale?

Each input is split into fractions |Aᵢⱼ| / S, where S is the largest absolute column sum (at least 1). The output rulers multiply collected litres by S. Bias buckets start with |bᵢ| / S litres. Every drop comes from a visible bucket.

Could an LLM run on buckets?

Let a number be an amount of water. Add by pouring together, multiply with a measuring mechanism, and keep the result in another bucket. We’ll start with Ax + b, then work toward Calc-GPT.

Negative numbers
Two buckets: x = V+ − V−. Neither volume is negative.

Shaped tanks
Shape maps volume to height. A float-controlled measuring bucket converts that height back into output litres.

This layer splits, never copies
Input water is divided among the weights. Calibrated output rulers recover the numerical result without adding water.

What is assumed in this first version?

For this fixed matrix, each input pours through a splitter. Branch (i,j) takes the fraction |Aᵢⱼ|/S, with S = max(1, largest absolute column sum). The remaining fraction goes into the visible spare-water bucket. After the input pour settles, the product and bias buckets open into the signed output pairs. The final reading is S × (V+ − V−) = Ax + b. Output volumes come only from incoming water, never from precomputed answer targets.

Inputs start with |x| litres, and bias buckets with |b|/S litres. Positive and negative output buckets use the same calibrated height scale: one litre represents S units. No supply is connected during a run. Ideal splitter ratios, leak-free buckets and sequenced gates are assumed; flow timing is illustrative, not a CFD simulation.

For a smooth, strictly increasing h = f(V), the required cross-sectional area is A(h) = 1 / f′(f⁻¹(h)). Decreasing functions need a reversed readout or a complementary mechanism; exact plateaus and singular endpoints require idealization or approximation. Draining the shaped tank still returns V, so a separate transducer is essential.

The operation list follows the existing Calc-GPT: embeddings, causal attention, LayerNorm, ReLU MLP and token selection. Other LLMs may add RMSNorm, rotary positions or non-monotone activations such as GELU/SiLU. There is no running LLM or matrix chain on this page yet.
