# Coastal ground textures

The island terrain uses four locally bundled [CC0](https://polyhaven.com/license) surface scans from Poly Haven.

| Material | Scan |
| --- | --- |
| Sand | [Coast Sand 03](https://polyhaven.com/a/coast_sand_03) |
| Grass | [Grass Ground](https://polyhaven.com/a/grass_ground) |
| Stone | [Rock Face 03](https://polyhaven.com/a/rock_face_03) |
| Snow | [Snow 01](https://polyhaven.com/a/snow_01) |

Each 512-pixel tile combines the first two channels of the OpenGL normal map and contrast-adjusted luminance from the diffuse scan. The game applies its own biome colors.
